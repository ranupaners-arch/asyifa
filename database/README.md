# Database lokal

1. Jalankan MySQL dari Dbngin.
2. Di TablePlus, buat koneksi MySQL ke `127.0.0.1:3305`.
3. Jalankan seluruh isi `schema.sql`.
4. Salin `.env.example` menjadi `.env.local` lalu isi kredensial lokal bila berbeda.

Schema ini baru mencakup fondasi booking. Tabel produk, order, pembayaran, dan activity log ditambahkan setelah booking teruji.
